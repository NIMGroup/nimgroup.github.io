## 关于实验室

神经影像智能理解实验室（NIMG@NJUST）聚焦 **脑科学 × AI × 智能医学** 交叉前沿，探索脑连接组、脑机接口、精准神经导航、人脑数字孪生等核心研究方向。

我们坚持务实的科研理念：

> 不迷信刷榜，不沉迷堆模型，而是坚持解决真实问题，打造可解释、可复现、可落地的技术。

我们期望每一个科研灵感，都能成长为一篇论文、一套代码、一个开源工具、一款产品，甚至一次改变临床实践的创新。如果你热爱科研、喜欢写代码、敢于探索未知，NIMG 或许正是你下一段旅程的起点。

---

## 研究方向

- **脑连接组学**：多模态脑网络构建、脑个体差异解析、人群脑图谱研究
- **脑机接口**：非侵入式神经信号解码、多模态融合、闭环神经调控技术
- **精准神经导航**：医学影像智能分析、术中靶点定位、临床导航系统研发
- **人脑数字孪生**：脑结构与功能数字化建模、生理仿真与疾病预测

## 技术特性

- ⚡ **高性能静态站点**：基于 Hugo v0.147.2 构建，页面加载速度快，移动端与桌面端适配良好
- 🎨 **极简学术风格**：基于 PaperMod 主题深度定制，适配实验室成果展示、招生招聘等学术场景
- 🚀 **自动部署流水线**：集成 GitHub Actions 工作流，代码推送至 `main` 分支后自动构建并发布
- 🔧 **本地开发友好**：支持热重载预览，便于内容迭代与样式调整
